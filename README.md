# Resume Clean Review Skill

Use this ChatGPT skill to compare your résumé with a job posting and tailor a one-page résumé for applicant tracking systems.

## Install

1. [Download the skill ZIP](https://github.com/susanzhang-byte/Resume-Clean-Review-Skill/archive/refs/heads/main.zip).
2. In ChatGPT, open **Plugins** and select **Skills**.
3. Select **Create**, then **Upload from your computer**.
4. Select the ZIP file. Install the skill if ChatGPT prompts you.

Skill upload depends on your plan and workspace settings. [See OpenAI’s installation guide](https://help.openai.com/en/articles/20001066-skills-in-chatgpt).

## Use the skill

1. Attach your current résumé.
2. Paste the full job posting or share its link.
3. Ask ChatGPT: “Use Resume Editing to score and tailor my résumé for this job.”
4. Read the match score. It estimates how well the original résumé supports the job requirements.
5. Download the two Word files. Use the clean copy for final review. Use the review copy to check edits and see suggestions for metrics to add.

## Review before you submit

**A person must always review the final résumé before you submit it.** Check each claim, date, title, and number. Confirm that the résumé reflects your experience. Add suggested metrics only when you can verify them. Submit the clean copy after your review.

## See comments in Word

1. Download the review résumé.
2. Open it in Microsoft Word.
3. On the **Review** tab, select **Show Comments**.
